# -Industrial-Parallel-Link-Robot-Arm-FANUC-Style-
📌 Project Overview
This project features a high-precision industrial robot arm designed using SOLIDWORKS. The design is inspired by the FANUC M-410iC series, utilizing a Parallel Linkage Mechanism and an RV Reducer (Cycloidal Drive) to achieve high payload capacity and motion stability.

Key Focus: Mechanical integrity, motion synchronization, and industrial-grade power transmission.

🛠️ Technical Specifications & Features
1. High-Torque Transmission (RV Reducer)
The core of the joint mechanism is a custom-modeled RV Reducer.

Cycloidal Motion: Engineered to convert eccentric orbital motion into pure rotational output.

Precision: Zero-backlash design simulation for smooth robotic maneuvers.

2. Parallel Linkage System
Dynamic Stability: The parallel link design moves the heavy motor weight towards the base, reducing inertia.

Load Distribution: Dual-support "Fork" design to handle high bending moments during operation.

3. Industrial Housing Design
Casting-Inspired Geometry: Designed with optimized fillets and ribs for structural strength.

Cable Management: Integrated internal bores for protected routing of servo and sensor cables.

🚀 Skills Demonstrated
3D Modeling: Expert use of Loft, Shell, and Hole Wizard tools in SOLIDWORKS.

Mechanism Design: Understanding of cycloidal drives and parallel kinematics.

Assembly Management: Managing complex sub-assemblies and mechanical mates.

Engineering Analysis: Structural optimization for weight reduction.
